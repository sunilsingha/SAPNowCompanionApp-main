### Artifactory Access Setup

In order to run `npm install` you need to make sure you have an auth token for the [Internet Facing Artifactory](https://common.repositories.cloud.sap/) (Use SAML SSO login).
Please follow [this guide](https://pages.github.tools.sap/scs-services/documentation/docs/kb-dev-setup-node/#setup-global-authentication) to setup global authentication.

## Getting Started

1.  Clone repo to your local machine.
2.  Run `npm install` to install dependencies.
3.  In the project directory, you can run: `npm run dev` to run project
